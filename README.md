# كيف تشغّل الموقع؟ (لـ وزارة الخارجية - الشؤون المالية)

## المطلوب مرة واحدة
1. جهازك لازم عليه **XAMPP** (MySQL من أجل قاعدة البيانات).
2. جهازك لازم عليه **Node.js** (نسخة 18 أو أحدث).

## التشغيل بخطوة واحدة
1. افتح ملف **«ابدأ الموقع.bat»** في نفس المجلد (كليك واحد عليه).
2. لو ظهرت رسالة «قاعدة البيانات غير شغالة» → افتح **XAMPP Control Panel** واضغط **Start** أمام **MySQL**، ثم أغلق النافذة وشغّل «ابدأ الموقع» مرة أخرى.
3. والباقي بيشتغل لوحده: الخادم PHP، الموقع، ويفتح المتصفح تلقائيًا.

## لو حصل مشكلة
- **الموقع مش بيفتح؟** تأكد أنك أغلقت أي نافذة تانية من الموقع (لونها أسود) قبل التشغيل.
- **شاشة بيضاء؟** انتظر 10 ثواني وحاول التحديث (زر F5).
- **الرفع لا يعمل؟** تأكد أن MySQL شغال (خطوة 2 أعلاه).

## للأدمن
- بعد فتح الموقع اذهب إلى `/admin` وسجّل دخولك.
- اسم المستخدم: `admin` — كلمة السر: `admin123`
- **غيّر كلمة السر فور أول مرة** من لوحة التحكم ← الأدمنز.
